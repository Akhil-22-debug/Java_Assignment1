The Employee Payroll System is a Java-based mini project developed to demonstrate the practical implementation of core Object-Oriented Programming concepts along with file handling techniques. This application is designed as a menu-driven console program that allows users to manage employee salary records efficiently. The main objective of this project is to apply fundamental Java concepts such as classes and objects, constructors, access modifiers, method overloading, exception handling, string manipulation, and persistent data storage using files.
The system allows the user to add employee details including Employee ID, Name, and Basic Salary. Based on the given basic salary, the program automatically calculates salary components such as House Rent Allowance (HRA) at 20% and Dearness Allowance (DA) at 10%. The Net Salary is then computed by adding these allowances to the basic salary. This automation reduces manual calculation errors and ensures consistency in payroll processing.
To ensure data persistence, the application uses file handling with FileReader, FileWriter, BufferedReader, and BufferedWriter. Employee records are stored in a text file so that the data remains available even after the program is closed. When the application starts, it reads the existing employee data from the file and loads it into memory. Any new employee added during execution is written back to the file, maintaining updated records.
The project also includes a search functionality that allows users to find employee details using the Employee ID. This feature helps in quickly retrieving specific records without manually checking the entire dataset. The program uses an ArrayList data structure to store employee objects, making it easy to add, manage, and search records dynamically.
Constructors are used to initialize employee objects, and method overloading is implemented in the salary calculation method to demonstrate flexibility in functionality. Proper exception handling is included to manage file-related errors and invalid operations, ensuring smooth program execution.
Overall, this project provides a simple yet effective demonstration of Java programming fundamentals. It helps in understanding real-world application development by combining OOP principles with file-based data management. The system is user-friendly, easy to maintain, and designed to meet academic requirements for a basic payroll management application
